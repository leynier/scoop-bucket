# Scoop bucket for Alera

[Alera](https://alera.build) is a native, performance-first agentic development environment.

```powershell
scoop bucket add leynier https://github.com/leynier/scoop-bucket
scoop install leynier/alera
```

Requires 64-bit Windows.

Alera does not update itself when Scoop owns the installation. Settings shows `scoop update alera` and can run it for you.

`bucket/alera.json` is generated by the Alera release workflow from `packaging/scoop/alera.json.tmpl` in [leynier/alera](https://github.com/leynier/alera). Send changes there, not here.

The manifest lands with the first stable release that publishes a Windows `.zip` asset; releases up to v0.36.0 only carry a `.tar.gz`.
